# Immersive IMAX Cinema

纯前端、离线优先的 3D 第一人称私人巨幕影院。HTML5 + CSS3 + 原生 ES Modules + Three.js r180 + Web Audio API。无需 npm，无需 Node.js 运行时，无需构建，无需 CDN。

## 启动

将下载的压缩包完整解压，进入包含 `index.html` 的目录：

```bash
python -m http.server 8080
```

打开 **http://localhost:8080**。某些系统命令为 `python3 -m http.server 8080`。

不要直接双击 `index.html`。ES Module、视频纹理、WASM、AudioWorklet、IndexedDB 受本地文件安全策略限制，需要 HTTP 来源。Python 只提供静态文件；影片、3D、音频和模型下载逻辑全部在浏览器执行，没有后端 API。

开发源码仓库的可部署目录是 `dist/`，在该目录执行相同命令即可。下载包将 `dist/` 展开为项目根目录，已经可以直接部署到任意支持 JS/WASM 的静态服务器。

## 第一场观影

1. 打开后先进入真正的 3D 大厅，不会直接出现普通播放器。
2. 选择本地 MP4 / WebM / OGG，或点击“使用内置试映短片”。短片为本项目程序生成的 12 秒 H.264 / AAC 2.0 素材，完全本地，无第三方影片。
3. 首次进入显示操作指南，随后点击“进入观影模式”锁定鼠标。也可以选择“使用拖动视角”。
4. 入场后有一段选座时间（**默认 60 秒，可在入场前于大厅面板或「设置 → 影院」调到 0–180 秒**）。可沿侧边或两条内部过道行走，也可以打开座位图选择座位。把准星对准座位，座椅会亮起橙色描边，按 E 直接入座；已入座时再按一次 E 起身。
5. 未选座也不会卡住：时间到时影片**直接从你当前的位置和视角开演**，影院不会替你挑座位、也不会把你挪到别处。**坐下去再站起来不会刷新倒计时**，影片一旦开始，起身也只是站起来——影片不暂停，倒计时也不会重开。想坐下随时按 E，按 R 才由影院带你去评分最佳的位置。
6. 入座不会跳过剩余倒计时。倒计时归零后**直接开演，不需要再点按钮**：先授权并暂停保留起点，约 650ms 黑场后开始播放，银幕与声音在约 1.5 秒中渐入。只有在浏览器拒绝自动播放（或还没有选择影片）时，才会退回「开始观影」按钮作为后备；空格同样可以直接开演。重播也是一点就走。
7. 暂停保留当前画面，等待 500ms 后缓慢增加部分壁灯和阶梯灯。继续播放恢复观影灯光。
8. 结束后保持最后视频帧，逐渐恢复灯光与环境声，显示重播及返回大厅入口。

场景不会渲染胸口、手、腿、膝盖或任何第一人称角色身体。碰撞体仅存在于数学计算中。

## 离线与 URL 的边界

- **本地视频支持完全断网播放**。使用 `URL.createObjectURL(file)`，不会上传、复制或默认缓存整个影片。刷新页面后需要重新选择本地影片，浏览器不会保留任意文件访问权限。
- 本项目自带 Three.js、实际使用的所有扩展、Draco / KTX2 解码器、Meshopt、程序化场景、纹理、海报、环境音和试映短片。运行时没有字体、图标或第三方 CDN 请求。
- **视频 URL 需要网络**，仅支持 HTTP(S) 视频直链，不支持网页播放地址、付费平台、DRM、HLS/DASH 清单或插件解码器。
- 远程服务器必须允许匿名 CORS。提示 CORS 时：**该视频服务器禁止跨域访问，请使用本地视频文件。** 浏览器可能不区分网络故障与 CORS，界面会一起说明，不能精确诊断所有服务器错误。
- HTTPS 页面不能加载普通 HTTP 影片；请使用 HTTPS 直链或本地 HTTP 服务。
- **模型 URL 与影片 URL 不同**：模型下载并保存全部依赖到 IndexedDB 后可离线重用；远程整部影片不会自动缓存。
- `sw.js` 在 localhost / HTTPS 的首次成功访问后缓存完整应用壳与默认资源。它只缓存项目文件，不缓存用户影片、外部 URL 或模型响应。首次从未打开过的远程站点不能凭空离线启动。最可靠的离线部署方式是下载本项目并运行本地静态服务。
- IndexedDB 属于当前来源。更换域名、协议、端口或浏览器会使用不同资源库；清理站点数据会删除模型。浏览器仍可能按其配额策略清理存储，建议保留模型原文件。

## 影院空间与性能

- 12 排 × 18 座，共 **216 个独立座位记录**，包括行列、世界位置、朝向、距离、偏移、可用/占用状态及评分。
- 座椅含弧角靠背、坐垫、扶手、杯架和底座，本色生成 8 个 InstancedMesh；另有 1 个不参与渲染的实例化包围盒专供准星拾取。静态建筑按材质合批，复用纹理与几何。
- **按摩座椅区**（国内影院常见做法）：第 8–10 排 × 第 7–12 座整块，也就是两条内部过道之间的中间座位块，共 18 座。靠背与坐垫整体包深色皮革、加按摩靠垫、金色包边和扶手控制面板，用 10 个 InstancedMesh 生成，**仅外观，暂不含按摩功能**。范围由 `js/seating/SeatManager.js` 的 `MASSAGE_ROWS` / `MASSAGE_COLUMNS` 常量定义，该区域恰好覆盖评分最高的第 9 排 9 / 10 座。
- 按摩靠垫的几何约束：入座后相机固定在座椅局部 `(0, seatedHeight, +0.03)`，相机近裁剪面为 0.08m，因此所有靠垫都由 `surface(y)` 贴着靠背正面定位并保持薄型（皮革外壳只比原靠背前凸 5mm），坐姿眼位到最近零件的余量为 **0.137m**（普通座椅 0.167m）。改动靠垫尺寸或位置时必须重新核对这个余量，否则转头就会看到靠垫被近裁剪面切开。
- 选座倒计时长度来自 `settings.countdown`（0–180 秒，`js/core/Config.js` 的 `COUNTDOWN_RANGE`），在大厅面板滑杆和「设置 → 影院」中都可调整并持久化；0 表示入场后立即自动入座。
- 巨型微曲面银幕原生比例 1.43:1；自定义 UV 着色器实现 contain / letterbox / pillarbox / crop，始终保持影片比例。16:9、2.39:1、竖屏等均不会被拉伸。
- 阶梯每排上升 0.28m。有吸音软包、穿孔纹理、侧墙扶手、低位灯带、出口、吊顶、风口、检修口及喷淋结构。
- 自动路线使用排间通道与过道；自由移动使用圆形玩家投影和旋转座椅矩形碰撞，分小步解算 X/Z，避免低帧率穿透。
- 座位评分 = 距离 30 分 + 中轴 25 分 + 仰角 20 分 + 声学甜区 20 分 + 排数 5 分。优先中后段中轴附近，同时避免靠屏幕过近、仰角过高。
- 鼠标目标角度与实际角度分离、指数阻尼、瞬时位移限速。呼吸效果默认关闭，开启时仅 ±0.012m。
- 准星选座：从相机中心发射一条不超过 26m 的射线，命中第一个可用座位即给出橙色描边（沿法线外扩的背面外壳，只画轮廓不遮座椅本体）与地面指示环，按 E 直接入座；已入座时 E 起身。拾取用的是独立的不渲染包围盒，因此替换座椅模型后选座逻辑不受影响。
- 灯光统一由 CinemaLightingManager 管理 ENTRY / SEATING / PRE_SHOW / MOVIE / PAUSED / FINISHED / FULL_LIGHT，支持 enabled / intensity / color，使用 easeInOut 式平滑插值。
- **银幕溢光就是影厅的主光源**。熄灯后银幕是唯一的大面积光源，真实影院里它会把侧墙软包、座椅轮廓、走道和天花板都照出形状，颜色还随画面变化。单个点光源做不到这件事（衰减太快，只剩一个亮点，典型的“屏幕很亮但墙上一点光都没有”），因此改用**银幕正前方一排点光源（decay=1，接近面积光的衰减）+ 一盏半球补光**来近似整块银幕；亮度设了下限，暗场也不会把整间厅吃掉。采样仍是每 160ms 只读 32×18 像素，颜色与强度都做过平滑与限幅。
- 银幕灯数量随画质：LOW 1 盏 / MEDIUM 3 盏 / HIGH 5 盏。LOW 也保留一盏，否则熄灯后整间厅会全黑。关闭「动态银幕溢光」只停止跟随画面颜色，银幕灯本身仍然存在。

| 画质 | 功能 |
| --- | --- |
| LOW | 直接渲染；关闭实时阴影、SSAO 与 Bloom；银幕溢光保留 1 盏灯；DPR 上限 1 |
| MEDIUM | PBR、单主光源阴影、动态溢光 3 盏灯、RenderPass + OutputPass；DPR 上限 1.5 |
| HIGH | PCF Soft Shadow、SSAO、微弱 Bloom、动态溢光 5 盏灯、OutputPass；DPR 上限 2 |

启动检测 WebGL2、GPU 标识、分辨率、DPR、CPU 线程数；自动模式持续低于约 32 FPS 时降级，不会来回抖动。实际最大像素预算约 830 万，4K 不会再乘 2× DPR。可手动调整画质和渲染比例。后处理失败会回到直接渲染。60 FPS 是目标，**不是对所有 GPU、视频解码器或用户模型的实测保证**。

SDR 视频使用 VideoTexture、sRGB 纹理/输出及显式视频色彩解码，关闭 mipmap；线性光照配合 NoToneMapping，避免给 SDR 影片重复套 ACES。HDR / Dolby Vision 的转换依赖浏览器与操作系统，不提供影院级 HDR 校准。

## 空间音频

音箱共 20 个：银幕后 L/C/R、LFE、SL1–4 / SR1–4、BL/BR、顶部 TF / TM / TR 左右三对。银幕后这四只的 z 严格小于幕布平面（幕布为微曲面，边缘向观众侧最大凸出 0.85m），因此它们是透声幕之后的声源，**在任何机位都不会遮挡画面**。声源保持世界坐标，AudioListener 的位置、forward 和 up 随相机更新。转头会改变听到的方向，推荐耳机。

```text
HTMLVideoElement → MediaElementAudioSourceNode（仅创建一次）
  → ChannelSplitter(8) → 声道矩阵 / 路由 Gain / 低通 / 延时
  → 各音箱的 PannerNode(HRTF)
  → Movie Gain → Master Gain → 压缩保护 → destination
  ↘ AudioWorklet 静音探针：检测实际输入声道及 RMS

本地生成的滤波噪声、脚步与座椅音 → 环境/效果增益 → Master Gain
```

- Mono：中置为主，弱左右与低频扩散。
- 2.0：左右前方主声场，L+R 提取弱中置，110Hz 低通送低频，侧墙、后方与顶部使用较小增益/延时扩散。
- 5.1：L R C LFE SL SR 对应映射；侧环绕分配到同侧四组。
- 7.1：增加 BL / BR，设置中可选择两种常见解码通道排列。
- **自动检测是浏览器实际输出的声道数，不是对容器原始音轨的完整解析**。某些浏览器在 Web Audio 前已降混，不能从 2.0 恢复离散 5.1。AudioNode.channelCount 不是可靠的原始音轨元数据。
- AudioWorklet 需要安全上下文（localhost 或 HTTPS）。不可用时默认 2.0，明确标注待检测并提供手动声道映射；不假装检测到了 5.1。
- 纯静音片段与无音轨影片可能无法仅凭 Web Audio 区分，界面会标注音轨存在性未确认。可用的浏览器音轨属性、实际解码字节和 RMS 用于补充判断。
- 2.0 与顶部扩散属于**模拟**，不是真正的 Dolby Atmos / IMAX 专有解码或硬件扬声器输出。HRTF 最终按设备输出，通常为立体声。
- Web Audio 不可用时降级为原生视频音频。浏览器本身不能解码的 DTS / TrueHD、视频编码或受保护内容仍不能播放。
- Audio Debug 显示 AudioContext 状态、采样率、检测/手动声道、音量、RMS、映射与 PannerNode 坐标。

## 离线模型资源管理

1. 大厅底部或“设置 → 影院”打开 **3D 资源管理器**。
2. 输入 `.glb` / `.gltf` URL，或从本地选择文件。GLTF 有依赖时可一次选中 GLTF + BIN + 纹理，或选择完整文件夹；每次只选择一个主模型。
3. URL 下载先检查 HEAD 的 Content-Length；缺失时尝试 Range 检查，仍未知则流式读取并实时检查。超过限制立即取消，不先下载完整大文件。
4. 根文件与全部依赖合计 **≤20 MB**，全部用户模型合计 **≤200 MB**。URL 与本地执行相同限制；保存事务内再次计算总容量，避免多标签页并发绕过。
5. 解析后显示独立 Three.js 预览：可拖动旋转，显示三角形、顶点、Mesh、材质、纹理、分辨率与包围盒尺寸。超过建议阈值显示警告，超过 500,000 三角形标注高复杂度。
6. **点击“保存到本地”才会写入 IndexedDB**。预览取消不会加入资源库。
7. 在“设置 → 影院”选择模型替换座椅、音箱、壁灯、出口灯箱、门或装饰。包围盒归一化到真实尺寸；座椅额外限制宽/深，保持碰撞与过道有效。
8. 重复模型只解析一次，按子 Mesh 使用 InstancedMesh。骨骼模型冻结为静态姿态，不播放动画；默认部件在新模型完整构造成功后才隐藏。解析/解码失败保留默认影院。
9. 刷新时根据设置优先读取本地记录与依赖 Blob。相同模型 URL 命中缓存后不重复访问外网。
10. 删除模型前显示确认，清除同一记录的 Blob、全部依赖与元数据；使用该模型的部件恢复默认。此版本不单独生成或持久保存缩略图。

推荐：三角形 <100,000、Mesh <30、材质 <15、纹理 ≤2048。批量用于 216 个座位时应进一步降低单模型复杂度。资源超过顶点/节点硬上限会被拒绝，防止压缩小文件解开后耗尽内存。

Draco WASM / JS、KTX2 Basis 转码器、Meshopt 都位于 `lib/three/`。KTX2 按 GPU 能力选择压缩格式，没有压缩纹理支持时可转 RGBA；文件本身损坏、缺少必需扩展或无法解码时报告错误并保留默认部件，不保证凭空恢复不存在的原始纹理。

只把模型当作 GLB / GLTF 数据处理，不运行外部 JS、HTML 或 iframe。解析时 LoadingManager 仅允许已缓存依赖、嵌入资源与本地解码器，禁止隐式联网。CORS 失败不会使用后端代理；请用允许跨域的 URL、本地导入或自己的静态服务器。

## 项目结构

- `index.html`：语义 UI、模态窗口、图标精灵；所有逻辑由本地模块导入。
- `css/`：main / lobby / cinema / controls，响应式界面。
- `js/core/`：Config、CinemaApp、统一状态机、渲染与后处理。
- `js/scene/`：大厅、影院、座椅、巨幕、建筑、音箱、程序化材质及静态合批。
- `js/camera/`：第一人称、阻尼、限速、碰撞与拖动降级。
- `js/seating/`：座位索引、评分、路线与入座动画。
- `js/video/`：本地 / URL 导入、元数据、播放与错误处理。
- `js/audio/`：声道矩阵、AudioWorklet 探针、音箱路由及环境音。
- `js/lighting/`：影院灯光状态机、低成本视频帧溢光。
- `js/assets/`：下载与 IndexedDB、GLTFLoader 封装、预览、场景对象工厂。
- `js/ui/`：大厅、播放器、设置与资源 UI。
- `js/utils/`：配置存储、数学函数及性能监控。
- `lib/three/`：Three.js r180、全部实际传递依赖、列出的加载器与后处理、解码器及许可证。
- `assets/first-light.mp4`：本地试映短片。
- `sw.js`：完整静态资源离线缓存清单。
- `tests/browser-tests.html`：用户设备真实 WebGL / 视频 / 音频 / IndexedDB 自检。
- `tests/core-tests.mjs`：开发逻辑回归测试，使用 Node 内置 test / assert，不属于运行依赖。
- `tools/make_demo.py`：开发时生成已交付的试映视频；用户无需运行。

影院几何与纹理由代码生成，故无需额外模型下载或缺省纹理文件。未来可在 `models/` 中增加自带资源。

## 测试与验收

开发逻辑回归运行方式（可选，仅开发者需要 Node）：

```bash
node --test tests/core-tests.mjs
```

已执行的测试结果和验证边界见 `TEST_REPORT.md`。逻辑/几何/音频图测试不等于真实 GPU 或浏览器播放测试。

启动服务后打开 **http://localhost:8080/tests/browser-tests.html**，点击“开始本机自检”。此页面会真正编译 WebGL shader、播放本地测试视频、验证后处理与 Web Audio，并往 IndexedDB 写入一个临时模型后读取、解析并删除自己的测试记录。不会清理用户模型。

人工验收：

| 操作 | 预期 |
| --- | --- |
| 断网，启动本地服务，打开主页 | 大厅、灯箱、材质、默认影院都能显示 |
| 选择本地影片或试映短片 | 时长、格式、分辨率、比例显示，进入按钮可用 |
| 首次入场 | 显示指南与鼠标锁定入口 |
| 自由走动、看向下方 | 阶梯正常、椅墙不能穿越、没有任何可见身体 |
| 选座时间内选座 | 平滑入座，WASD 停止移动，倒计时继续 |
| 倒计时中途坐下再按 E 起身 | 倒计时**从原来的剩余时间继续**，不会回到起始值 |
| 完整等候倒计时不选座 | **原地**直接开演，观众不会被移动到任何座位 |
| 入场前把选座时间设为 0 秒 | 入场后立即原地开演，不自动入座 |
| 入场前把选座时间设为 180 秒 | 大厅提示与入场后的倒计时都按 180 秒开始，刷新后仍是该值 |
| 观影中按 ~ | 鼠标指针在锁定 / 解锁之间切换，画面与影片不受影响 |
| 开始 / 空格暂停 / 继续 | 影片、灯光、环境音与控制栏协调变化 |
| 熄灯后看电影 | 侧墙软包、座椅轮廓、走道都能看出形状，颜色随画面变化；不是“屏幕亮、墙上全黑” |
| 画面切到暗场 | 整间厅仍保留可辨识的轮廓，不会变成纯黑 |
| 向左转头 | 银幕声源仍在世界中，听感转向右侧 |
| 影片播放中按 E 起身再入座 | 影片不暂停、画面不回到映前、倒计时不重开，E 可再坐下 |
| R / 离开座位 / 全屏 | 平滑复位、恢复找座流程、真实全屏或明确降级提示 |
| 坐到按摩座椅上转头 | 靠垫不会穿模或消失 |
| 试映片结束 / 重播 / 返回 | 保留末帧、恢复灯光；点「重新观看」直接开演 |
| 本地 GLB 或含纹理 GLTF 导入、取消预览 | 不保存、不替换默认场景 |
| 导入、预览、保存、替换座椅，断网刷新 | 模型与全部依赖从 IndexedDB 恢复 |
| 本地 / URL >20MB、总缓存 >200MB | 拒绝；未知大小超限中断 |
| CORS / 错误编码 / 播放被拒绝 | 中文错误、保留重选/重试入口，基础影院不崩溃 |

`window.cinemaDiagnostics()` 返回只读诊断快照：状态、倒计时、座位、FPS、画质、Three.js 版本与音频信息；选座时间通过大厅面板或设置里的滑杆调整，没有在观看过程中跳过流程的入口。
